# 2026-10-18: HyperFrames, measured

A short session. The user pasted a link to `heygen-com/hyperframes` with no other words, and every repo
in the session had a branch named `claude/hyperframes-repo-w24mmu`. Claude read it as "is this useful
for us?" and answered in `_RDA`, the repo with the video pipeline.

## What we did

1. Read HyperFrames' README, license (Apache 2.0) and CLI. It renders HTML to MP4 with headless Chrome
   and FFmpeg, like Remotion, and adds local tools Remotion does not have: Kokoro TTS, whisper
   transcription, background removal, a `check` gate with WCAG contrast. Telemetry is on by default.
2. Ported explainer scene S5 (`rda status` / `rda score`, 12 s) to one HTML file with the same fonts,
   colors, frame timings, easing curves, SFX cues and music bed.
3. Rendered it with HyperFrames and rendered the same 360 frames of `RdaExplainer` with Remotion, then
   compared them: SSIM per frame, loudness, and frames read side by side.
4. Rendered the Pass stamp as a transparent `.mov` and composited it, to check it fits `bake.py`.
5. Wrapped it all in `experiments/hyperframes/bakeoff.mjs` so the numbers can be reproduced, and wrote
   the results in `experiments/hyperframes/README.md`.

## What we found

- Same picture (SSIM mean 0.994, lowest 0.987), same loudness (-20.7 LUFS both), similar render time
  (12.8 to 17.3 s for 12 s of 1080p on 4 vCPU), and ProRes 4444 alpha output `bake.py` can use.
- So HyperFrames could do the job, but it would do the same job. Decision D17: keep Remotion.
- The interesting part is not the renderer but the keyless local tools. Kokoro TTS could unblock the
  explainer's narration (open item 3 from 2026-10-05) without an ElevenLabs key. Untested.

## What we got wrong

| What | What happened | Lesson |
|---|---|---|
| Typing the command from a GSAP `onUpdate` | The renderer seeks with events suppressed, so callbacks never run | Read the source of the seek before trusting a callback; use tweened properties or `tl.set` |
| A `.side p` rule in the port | It overrode `.eyebrow`; the eyebrow came out in the body font | The SSIM pass found it (frames at 0.949). Compare by numbers, then by eye |
| A comparison clip sent with no thumbnail | Called "internal"; CLAUDE.md says "an episode, an explainer, a short, anything" | No exceptions. A thumbnail was made for it afterwards (`experiments/hyperframes/thumb-A.jpg`) |
| The first skill draft overclaimed the explainer's cue wiring | It said every cue came from scene exports; three are hardcoded | An independent fact-check against the repo caught it, with nine other errors |
| S4 of the new video said "every sound sits on a frame a scene exports" before it was true | The rail's 14 cues were computed in the composition | Fixed in code, not text; a third render hashed identical to the second |
| The first mix's effects were too quiet to notice | Clicks at 0.15 to 0.3 under a 0.8 bed; CT asked for "sound" | Measure effect-to-bed contrast, not just integrated loudness |
| Default mastering went dynamic without saying so | `loudnorm` falls back when gain crosses the true-peak ceiling; mix 1 had too | `master_audio.py` reports it now; `--static` for effects-led mixes |
| A static master rang to +6.5 dBTP | Hard-limited clicks ring in the AAC encoder | 16 kHz roll-off before the limiter, ceiling 2 dB under the target |
| Judged the effects with the momentary meter | 400 ms averages clicks away | 50 ms RMS against a music-only stretch |
| Adding a voice left S2 saying "so the words on screen carry it" | The claim and a "text-led" chip were true for mixes 1 and 2 only | A sound change can falsify on-screen text: read every claim again after any change |
| Kept mix 2's effects (x2) under the voice | Effects only 5 dB under the voice | Render each layer alone and measure voice over bed and over effects |
| The closing hit and the voice's first word on one frame (S10) | Both cued at frame 8 | The cue audit includes the voice; the line moved to 16 |
| The script's brief used `Voice:` as a label | `narrate.py` read it as a line before any scene and refused | Label the brief `Narrator:`; `Voice:` lines only under a scene heading |

   (shown in a second render, checked frame by frame). Stills caught three layout defects; the thumbnail check caught
   two more; an on-screen claim was made true in code. Mastered to -15.9 LUFS / -1.9 dBTP.
4. **Style bible 0.2:** step rail, receipt card and scene bar motifs; MEASURED as a stamp verdict; a header label.
