## Scoring rubric

Score each candidate from 1 (poor) to 5 (strong) on each line. A candidate needs no 1s to be eligible.

| Criterion | Question to answer |
|---|---|
| Exam availability | Is there a usable real exam with a published key, or a published blueprint to generate from? |
| Time-boxable | Can an informed beginner make a real attempt inside the fixed window? |
| Visual story | Does the domain have processes, diagrams, or patterns that make good B4 visuals? |
| Cross-domain patterns | Will there be structural patterns that connect to other domains for B4b? |
| Honest baseline | Can the host truthfully claim no prior background? |
| Stakes fit | Is there a natural, safe reward and punishment for this domain? |
| Sensitivity | Is the content health, legal, or safety critical? If yes, the credibility plan in [risks.md](risks.md) item 5 is required |
| Series arc | Does it set up the next episode well? |

## Picking episode 001

The first episode sets the template for everything after it. Prefer the candidate with the clearest
real exam source and the least sensitivity, even if it is not the most dramatic. A clean first episode
is worth more than an ambitious one that stalls on rights or answer keys.
